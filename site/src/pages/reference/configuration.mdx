## What forces a re-ingest

Changing any of these changes the vectors already stored, so delete the affected documents and upload them again:

- `OLLAMA_EMBED_MODEL`, `OLLAMA_EMBED_PREFIXES` or `INGEST_CONTEXT_HEADERS`
- Collections created before the hybrid-search schema (they have a single unnamed vector)
- Documents ingested before the heading-split fix or the automatic title-header feature
- `.docx` files ingested before Word headings were preserved

The "What the model reads" settings don't change stored vectors, so they take effect on the next question with no re-upload.
