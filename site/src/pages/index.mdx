## What is LocalCortex?

LocalCortex is a fully local Retrieval-Augmented Generation (RAG) pipeline. Upload a file, ask it a question, and get an answer grounded in that file, with Ollama running the embedding and generation models, Qdrant storing the vector index, and Postgres keeping the conversation history. **No API keys, no external calls, nothing leaves your machine.**

<div className="pipeline">{`A. your files ─▶ load ─▶ chunk ─▶ embed (nomic-embed-text) ─▶ Qdrant
B. question  ─▶ retrieve ─▶ prompt ─▶ llama3 (Ollama) ─▶ answer + sources`}</div>

</section>

## How does it work?

<ol className="stage-list">
  <li className="stage">
    <div>
      <strong>Ingest</strong>
      <p>A .txt, .md, .pdf or .docx file is loaded, split into chunks along its natural structure, and embedded.</p>
    </div>
  </li>
  <li className="stage">
    <div>
      <strong>Retrieve</strong>
      <p>A question is embedded and matched against the index; only chunks that clear a calibrated relevance threshold are used.</p>
    </div>
  </li>
  <li className="stage">
    <div>
      <strong>Answer</strong>
      <p>The matched chunks are placed in a prompt and streamed back through the local model, citations attached.</p>
    </div>
  </li>
</ol>
